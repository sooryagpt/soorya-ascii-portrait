## How to Run

1. Install Python 3.
2. Install dependencies:

```bash
pip install -r requirements.txt
```

3. Run the script:

```bash
python ascii_portrait.py your_photo.jpg
```

Your ASCII portrait will be saved as `portrait.txt`.
